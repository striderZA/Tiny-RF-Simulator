Updated Interaction Model

  • No dropdown in Spectrum Analyzer. It only displays which node is currently probed.
  • Left-click any output pin in the node editor to set it as the active probe point.
  • The probed pin gets a green halo/glow to indicate it's being observed.
  • Multiple probes: Could support Shift+click to add additional probe points (overlay view). For now: single probe only.
  • Spectrum Analyzer widget shows the probed node's label and computed power/frequency info.
