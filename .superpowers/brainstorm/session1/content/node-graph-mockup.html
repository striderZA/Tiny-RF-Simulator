Key Behaviors

  • Add/Remove: Right-click context menu on canvas to add Generator or Amplifier nodes. Select node + Delete key to remove.
  • Connect: Click-drag from an output pin to an input pin. Only output→input allowed. Multiple outputs can feed one input (sum/power combine).
  • Spectrum Analyzer: Always present as a "view" node. Any connected node's output spectrum is displayed. Multiple inputs = overlay.
  • Configuration: Double-click a node (or its title bar) to open its existing config widget in a separate ImGui window.
