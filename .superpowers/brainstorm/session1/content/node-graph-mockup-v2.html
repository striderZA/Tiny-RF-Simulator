Updated Behaviors

  • Node Graph: Only DSP components (Generator, Amplifier) appear as nodes. No spectrum analyzer node.
  • Spectrum Analyzer: Always-visible separate panel. Dropdown selects which node's output to observe. Sets that node's view_enabled = true.
  • Deletion: Removing a node disconnects all its links. Downstream nodes become unconnected and stop receiving input.
